Wallpaper + displays

Any visual behind your icons. Mirror or Span, per display, survives Explorer restarts.

Set the desktop as your stage

Live Wallpaper runs the visual behind your desktop icons while you work, on any mix of displays, driven by whatever IKANDY is listening to.

It is a set-and-forget output: open Sources & Settings → Live Wallpaper, click a display to toggle it on, and get back to work. Change the visual any time from the console or STAGE and the desktop follows. The wallpaper survives Explorer restarts, and it keeps rendering even when the main IKANDY window is covered or minimized.

Fit mode: Mirror or Span

Mirror (the default) puts the same feed on each screen you picked. Span stretches one image across all attached displays as a single canvas; it needs two or more screens, and it takes over the routing while it is on. Both modes persist.

The output window

Separate from wallpaper, the multi-display output window is a broadcast surface: mirror the main view onto the displays you choose, each mirror with its own gain, or span one continuous visual edge to edge (the titlebar hides so nothing interrupts the image). Right-click the fullscreen button for a quick "send to a second screen" chooser. Add Hide-UI mode and the pixels are all that is left.

Overlays

The Now Playing card and Lyrics each have a broadcast switch: show them on the second screen, Spout, and recordings, or keep every output clean.

Good to know

  • Toggle wallpaper off any time from the same panel if anything misbehaves.
  • Performance cost scales with the visual you pick. Calm scenes cost very little; heavy compute scenes cost more.
Tier note Desktop wallpaper ships in the Pro tier; see pricing. The Steam page is authoritative.
