Visualizers + presets

Five engines on one stage. The MilkDrop library, cycling, reactivity, and your own presets.

Visualizers

Five Engines,
One Stage

The engine tabs on the console pick what is driving the stage: MilkDrop, GLSL, WebGPU, Spout, or Image. MilkDrop is the deep preset library this page covers; GLSL and WebGPU run hand-built and imported scenes, Spout turns a live feed into a source, and Image layers FX shaders over a photo.

MilkDrop, reborn

The MilkDrop engine is built on Butterchurn, a WebGL port of the legendary MilkDrop visualizer. IKANDY ships a deep preset library: the base collection, extra curated packs, and an Image category that layers especially well over a background photo.

Cycling looks

AUTO on the console cycles presets on a dwell timer you set: how many seconds each look holds before the next. The sliders icon next to it opens timing and blend controls; a longer blend morphs cinematically between looks, a short one cuts kinetic. Auto-cycle draws from a shuffle bag, so every preset in the active pool plays once before any can repeat.

Reactivity

On first launch IKANDY quietly scores the library in the background while you use the app, classifying each preset as reactive, non-reactive, or image-texture. The results are cached. In the browser, the REACTIVE filter narrows the pool to presets that visibly answer the music; if the scan has not finished, a Run Scan button is right there.

There is also a Reactivity master for the whole engine: turn it down and presets settle into calm ambient motion instead of going dark, turn it up and the beat drives harder.

The browser

Browse opens the full library with thumbnails. Hover any card for a live preview; click to load it on the stage immediately. Scene cards preview from a cached clip the same way. Tabs, favorites, hiding, flagging, and reordering are covered in Library.

Your own presets

In the browser, Custom Presets loads a folder of converted Butterchurn JSON presets, merged alongside the bundled library and remembered across restarts. Butterchurn uses a JSON preset format rather than MilkDrop's original .milk binaries; if a folder contains .milk files, IKANDY says so and points you at the converter.

Misbehaving presets Some presets produce invalid values on modern GPUs. IKANDY skips broken or near-black presets automatically and remembers them, so the cycle keeps moving. Anything questionable lands in the FLAGGED tab for you to judge.
